# Site de Imobiliária — Dark

Site de imobiliária em página única: fundo escuro com detalhes em dourado.

- **Barra de busca no topo** com abas Comprar, Alugar, Temporada e Permuta e filtros de cidade/bairro, tipo de imóvel e quartos.
- **Vitrine 1 – Oportunidades:** imóveis com preço antigo riscado e o novo preço em destaque.
- **Vitrine 2 – Imóveis no banner:** banner grande que alterna entre imóveis, com setas e miniaturas.
- **Vitrine 3 – Destaques:** mosaico com 6 imóveis na página inicial.

Todo o conteúdo dos imóveis (títulos, preços, endereços e fotos) está como dados de exemplo em `src/routes/index.tsx` — troque pelos dados reais.

## Como rodar

```sh
npm i
npm run dev
```

## Stack

TanStack Start v1 (React 19 + Vite 7), TypeScript, Tailwind CSS v4 (tokens em `src/styles.css`), shadcn/ui em `src/components/ui`. Rotas em `src/routes`, assets em `src/assets`. Sem banco de dados e sem login.
